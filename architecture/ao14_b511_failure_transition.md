# B511 failure refresh and separate local consumers

This Release 0.7 software API companion defines a bounded, pure library contract
for `vaillant`. It references the [public native B511 contract](../protocols/vaillant/ebus-vaillant-B511.md#b5-11-01-failure-mode-read-candidate)
first for wire claims. That contract's candidate evidence does not establish
physical support for this software view. Family interpretation is **Hypothesis**;
native support, physical effects and persistence remain **Unknown**. Qualification
is always false. A selected view, candidate label or successful calculation grants
no permission. This page adds no protocol qualification or catalog entry.

The supplied issue contract is the source for the software rules below. It is
independent of AO13 and requires no code merge to check its finite examples.
Refs: #935; partial companion to #736, with no umbrella closure.

## Function and JSON boundary

```go
func Ab13Ao13Interpret(ab13ao13Input json.RawMessage) (json.RawMessage, error)
```

The implementation contract uses only the Go standard library in package
`vaillant`. It describes no active request, executor, timer loop, UI, cache,
metadata listing, registration or runtime call site. There is no pending API
import or duplicate Entries/Lookup API. eBUS MCP compatibility and GraphQL parity
are unchanged. The owned artifacts here specify the API; they do not implement
or execute the Go function.

Input is a JSON object with required object members `context` and `fields`, and
optional object `arguments`. Context has integer `primary=181`, integer
`secondary=17`, string `direction="local"` and explicit string `view`.
`operation=1` is an integer required only for `refresh`. `initialize` and
`timer-consume` require operation to be absent; they are local software views,
not wire operations. A present operation of zero is not absence. Every supplied
context key, including opaque `family` and `variant` JSON values, survives
unchanged. Never select from a family label, name or payload length.

Fields are named byte arrays. Every element, including unknown fields and tails,
must be an integer in 0..255 (JSON booleans and floating point tokens do not count
as integers). `registration` and `prior_failure` use their first byte when
available and preserve any tail. `local_body` preserves its whole available span.
Missing and empty arrays remain distinct in `raw`; neither supplies a byte zero.
Arguments accept only the view's keys in the table below: integer means a JSON
integer, not a boolean; no additional integer range is inferred. Missing required
values produce a partial selected result when the view is otherwise known.

| View | Operation | Fields consumed | Arguments |
|---|---|---|---|
| `refresh` | integer 1 | `registration`, `prior_failure`, `local_body` | integer `index`, `selector`, `local_selector`, `count`; boolean `parsed` |
| `initialize` | absent | none required | none |
| `timer-consume` | absent | `prior_failure` | integer `index`, explicitly 0 |

Malformed JSON, duplicate object keys at any nesting depth, wrong JSON kinds,
invalid bytes and wrong/unknown argument keys return an error with no successful
JSON result. Validate all supplied bytes even for raw-only selections. Unknown
integer identities/operations, unknown direction/view, missing selection tokens,
or an operation supplied for a local-only view return structured raw-only
`Unknown`; never guess. A timer index other than zero is also `Unknown`.

## Results, selection and partial state

Output contains `context` (unchanged deep copy), `raw` (independent copy of all
supplied fields), `arguments` (independent copy only if supplied), `state`,
`fields`, `physical="Unknown"`, and `qualified=false`. The finite cases below
show complete output envelopes. All returned nested data is independent of input,
other fields and later calls. JSON round trips retain presence and state.

An available prior failure byte is retained as a boolean (nonzero true). Refresh
selection requires registration **bit0** set, `index != 1`, and
`selector != local_selector`; both exclusions apply independently. On selection,
`parsed=true`, nonzero count and at least nine available local bytes admit a
successful refresh. Copy exactly the first nine bytes; set failure to copied
byte index 7 **bit0**, not whole-byte nonzero. Preserve a tenth byte in `raw` only.
Count and available span are independent. A short admitted body (length 0..8)
is incomplete and retains prior failure; no out-of-span read or clearing occurs.
A zero count, failed parse or skipped entry retains prior failure. A skip does
not require a body. This is a local state rule, not a nine-byte physical reply
claim.

Initialize clears failure without refresh, prior state or operation. Timer-consume
uses explicit local index0 and only retained prior failure: nonzero selects
`error` and argument120, zero selects `capability-path` with no error argument.
No fresh-refresh-before-timer order is established or required. There is no
implicit temporal orchestration or persistence promise.

| Result field | Raw source | State and exact result |
|---|---|---|
| `failure` | retained prior bytes; copied byte index 7 on refresh; empty on initialize | `Hypothesis`, number 0/1, flags `failure` false/true, exact calculation `Proven` |
| `copied_body` | exactly first nine body bytes on success | `Hypothesis`, no number; admitted short body is `incomplete` with available raw bytes |
| `path` | prior bytes | `Hypothesis`, label `error` or `capability-path`, no number |
| `error_argument` | empty | `Hypothesis`, number120, only on error path |

Complete selected results have state `Hypothesis`; unresolved required selected
inputs have state `partial`. Missing/empty registration or body in an attempted
refresh retains available failure and an incomplete copied-body field. Missing
arguments retain available failure but admit no copy. Missing/empty prior on a
skip leaves failure incomplete with no number. Complete independent sibling
fields survive partial interpretation; unknown/unmodelled raw fields do not
erase them. Explicit raw-only `Unknown` has empty semantic `fields`.

Every semantic field remains `Hypothesis`, even when exact boolean/bit
calculation is independently `Proven`. No number is emitted for incomplete,
unmapped, unit-conflict or unknown-order fields. This view defines no carrier
outside a candidate domain; a future explicitly specified outside-domain carrier
would need `candidate_domain=false` alongside its number. There is no inferred
unit, family applicability, physical effect or native qualification.
