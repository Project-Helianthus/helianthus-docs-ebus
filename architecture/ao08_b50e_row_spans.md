# B50E isolated row spans and partial results

This is a Release 0.7 software API companion for issue #930, a partial child of
#736. Its contract is independently testable without AO07 or a code merge.
Nothing is stable before Helianthus 1.0. No active request, executor, UI,
scan-default, catalog, or registration change follows from this page.

The public native reference is [B50E logger service](../protocols/vaillant/ebus-vaillant-B50E.md#data-types-of-the-rule-read-reply).
Its nineteen candidate OP02 rows, opaque widths and raw inverse bytes provide
the native context. **Hypothesis** describes these family interpretations;
physical support, effects and persistence remain **Unknown**. There is no native
qualification here. In particular, the native page's general little-endian
sentence does not establish row-specific byte order for this API: the supplied
software contract deliberately leaves every multi-byte row order **Unknown**.
No multi-byte number or temperature is calculated. Any conflict stays visible.
No new native observation is asserted by synthetic examples.

## Pure API and selection

In package `vaillant`, using only the Go standard library:

```go
Ab07Ao07Interpret(ab07ao07Input json.RawMessage) (json.RawMessage, error)
```

This is a selected field/state interpreter, without a global cache, generic
catalog, metadata listing, pending API import or runtime call site. All new Go
identifiers must start with `ab07ao07` or exported `Ab07Ao07`; Go tests start
with `TestAb07Ao07`. Existing library symbols and literal JSON labels retain
their names. There is no second family schema or Entries/Lookup API.

Input is a JSON object with required object members `context` and `fields`, and
optional object `arguments`. The context selectors are integer `primary=181`,
integer `secondary=14`, integer `operation=2`, string `direction="positive"`
and explicit string `view="row-spans"`. Absent selectors or different,
well-typed selector values yield structured raw-only `Unknown`; never select by
family, variant, name, payload length or a default view. OP03 is always raw-only.
Family and variant are opaque JSON values, independently preserved, as are all
other supplied context keys. They cannot confer applicability or qualification.

`fields` maps names to byte arrays, including `key` and `value`. Every array
element must be a JSON integer in 0..255; booleans, fractions, strings and null
are not integers. All named arrays, including unmodelled ones, are validated
and retained. `key` must contain exactly one byte to select a row. A missing,
empty or multi-byte key yields raw-only `Unknown`. A missing `value` also yields
raw-only `Unknown`; a present empty value for a known-width row is `partial`.
Key zero is present and opaque, not an absent selector. Row zero starts at the
first byte of the already isolated `value`; no enclosing-frame base is added.

There are no described argument flags or integers for this view, so only an
empty `arguments` object is accepted when supplied; no invented flags are
accepted. Omission and `{}` remain distinct. Malformed JSON, trailing JSON,
duplicate object keys at any depth (including opaque context), wrong JSON
kinds, unknown arguments, or invalid byte elements return an error and no
successful result. Error text is not fixed by this contract. Missing top-level
`context` or `fields` is an error; missing selectors inside context are not.

## Output and spans

The output object has `context` (unchanged deep copy), `raw` (independent copy
of every supplied field array), optional `arguments` (independent copy only
when supplied), `state`, `fields`, `physical="Unknown"`, `qualified=false`.
Each semantic field has its actual available `raw` span and `state`; optional
`number`, `label`, `flags`, `reserved` and `candidate_domain` appear only when
specified. This view defines no flags, reserved bits or candidate-domain test;
those members are absent. This API design uses `value`, `inverse` and `status`
as semantic field names in the exact case table below.

Complete semantic spans carry `state="Hypothesis"`, even for unknown-order
words. Incomplete spans and unmapped fields carry `state="Unknown"` and no
number. Complete u8/i8 arithmetic also carries `calculation="Proven"`; that
never replaces the Hypothesis interpretation or promotes native support.
Signed8 uses the exact two's-complement carrier: FF is -1, 80 is -128 and 7F is
127. Key1 is only a Boolean carrier: byte 02 is truth-unqualified, without a
number or truth table. Key8 labels 0F `true`, F0 `false`, and no other byte.
No borrowed Boolean table, inverse-complement check or temperature unit/order
assumption is permitted. Status17 labels 00 `okay`, 55 `short-circuit`, AA
`interrupted`; other status bytes stay Unknown independently of the word.

`state="complete"` means all required spans for the selected row are present
and mapped at the permitted raw-span level, not that a multi-byte number or
native support is known. `state="partial"` means a selected known-width row is
truncated or a sibling is Unknown while another span remains useful. Preserve
all complete independent fields, including the value when companion bytes are
short. The explicit unmapped key8 branch, opaque keys 0/15/16, unrecognised key
and unselected contexts remain `state="Unknown"`. Opaque widths are Unknown,
never zero; preserve their entire value as an Unknown semantic span. Unselected
contexts and unknown keys have empty semantic `fields` and full `raw`.
Unmodelled tails stay in `raw.value` even though semantic spans stop at their
known widths. No earlier successful value is destroyed by a sibling failure;
no cross-call last-known-good cache is introduced.

No number is present for an incomplete, unmapped, unit-conflict or unknown-order
field. The wider API convention permits an explicitly specified outside-domain
carrier number with `candidate_domain=false`; this view defines no such case.
Every output is independently owned: modifying input after a call, any nested
output, or a later call must not mutate another result. Context, raw, semantic
spans and arguments must not share mutable nested memory. Presence, empty/zero,
error and state distinctions survive JSON round trips. Admission is fail-closed:
a candidate label grants no permission. No eBUS MCP surface changes here;
future GraphQL/MCP exposure must preserve the same values, grades, raw bytes,
presence and errors without triggering hardware or qualification.
