# API pages

This index lists every page under `api/`: the application interfaces of the
gateway and its companions.

A page that was renamed to a lowercase kebab-case file name shows its status
from the closed set implemented, accepted contract, candidate, historical and
unknown. The status repeats the page's own statement; the [status
table](../architecture/page-status.json) quotes that statement for each renamed
page. Other pages keep the status statements in their own text.
